# web-UAT-companion
A web based companion to conduct UAT using excel based test cases. It aims to automate the testing. However, it asks for human intervention where needed. 

## Install as a Claude Code plugin

```
/plugin marketplace add accessmandy1986/web-UAT-companion
/plugin install web-uat-companion@web-uat-companion
```

See [web-uat-companion/README.md](web-uat-companion/README.md) for workspace setup and usage. Credentials, test cards,
run results and defect drafts stay in a local workspace (`*.local.json`, `runs/`, `defects/`) and are never committed.
